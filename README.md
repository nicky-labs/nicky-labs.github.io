# Nicky Pisitpong portfolio

Personal portfolio for `nickypisitpong.com`, hosted free on GitHub Pages.

## Publish this redesign

1. Open the `nicky-labs/nicky-labs.github.io` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Drag everything in this folder into the upload area. Include the `assets` folder.
4. Confirm **Replace files with the same name** if GitHub asks.
5. Click **Commit changes**.
6. Wait 1–3 minutes and refresh `https://nickypisitpong.com`.

The custom domain and Porkbun DNS records do not need to be changed.

The résumé button currently opens the on-page professional history. The original PDF is not included because it displays a personal phone number.
